# QuizCraft

## About the project

QuizCraft is smart quiz generator that automatically creates quiz questions from study material.

## Objectives
- Generates quiz questions automatically.
- Make revision easier.
- Save time.
- Provide an easy quiz interface.

## Technologies Used
- Python
- Streamlit
- NLTK
- Pandas
- Scikit-learn
