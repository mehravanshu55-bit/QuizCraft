# QuizCraft – Smart Quiz Generator

QuizCraft is a Python-based quiz generator that creates MCQ quizzes from study material.

## Features

* User Login and Sign Up
* Enter Text or Upload PDF
* Select Topic
* Select Difficulty
* Select Number of Questions
* Generate MCQ Quiz
* Calculate Score
* View Quiz Results
* Save Quiz History

## Technologies Used

* Python
* Streamlit
* SQLite
* PyPDF2
* NLTK
* pandas
* scikit-learn

## Project Files

* `app.py` – Main application
* `database.py` – Database functions
* `quiz_generator.py` – Quiz generation
* `text_processor.py` – Text and PDF processing
* `requirements.txt` – Required libraries
* `README.md` – Project information
* `SPRINTS.md` – Project sprints

## How to Run

```bash
streamlit run app.py
```
