- Set up project structure
- Set up python environment
- Install python libraries
- Create basic streamlit app

- Add text input
- Take study material from user
- Display entered text

- Select useful information for questions

## Sprint 7 - Quiz interface
- Display questions using streamlit
- Add answer selection
- Add submit button

## Sprint 8 - Score and Improvements
- Calculate quiz score
- Show correct and incorrect answer
- Improve user interface
- Add error handling

## Sprint 9 - Testing
- Test with different study material
- Find and fix bugs
- Improve question quality

## Sprint 10 - Finalization
- Perform final testing
- Complete documentation

- Prepare PPT and project report
